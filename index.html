Settings

Paste your own API key if you want to call a model. The key is stored only in localStorage and is sent only to the provider URL you set. Leave it empty to stay in offline echo/demo mode.

Many providers block browser requests because of CORS. If a live call fails, the key may still be valid, and demo mode will keep working without a network call.
